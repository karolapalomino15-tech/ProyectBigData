Objetivo General: 
Diseñar e implementar una solución basada en arquitectura de Big Data de complejidad media para la detección oportuna de comportamientos anormales en procesos industriales, utilizando el conjunto de datos del Tennessee Eastman Process (TEP) como caso de estudio representativo.
